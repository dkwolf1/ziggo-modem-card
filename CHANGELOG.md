# Changelog

## 1.1.0

- Show the modem-reported DOCSIS version in the card header when Ziggo Modem integration v1.6.8 or later exposes it.
- Add GitHub issue forms for bugs and feature requests.

## 1.0.0

- Standalone Home Assistant dashboard card for the Ziggo Modem integration.
- Signal score, DOCSIS readings, a diagnostics dialog with the integration's reason for the score, and a 24-hour or 7-day downstream SNR chart.
- Dutch and English interface and documentation, visual configuration editor, and installation through Home Assistant Marketplace or a manual dashboard resource.
- Add linting, formatting, unit and browser tests, pre-commit, and GitHub Actions validation.
- Document maintenance, release steps, and private vulnerability reporting.
