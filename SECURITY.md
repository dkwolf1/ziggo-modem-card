# Security policy

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/dkwolf1/ziggo-modem-card/security/advisories/new). For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/dkwolf1/ziggo-modem-card/issues).

Include the affected card version, Home Assistant version, browser, and enough detail to reproduce the issue. Remove credentials, tokens, and identifying modem information before sending logs or screenshots.
